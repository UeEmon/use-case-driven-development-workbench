# UC-003 整備記録を登録する

**主アクター**: 整備士　**事前条件**: 整備士がログインしている　**事後条件**: **整備記録** が登録され、**機材** の次回整備期限が更新されている

## 基本コース
1. 整備士は「整備記録登録画面」で **機材** の機体登録記号・実施日時・整備内容・次回整備期限を入力し、登録ボタンを押す。
2. システムは機体登録記号に該当する **機材** を取得する。
3. システムは次回整備期限が実施日時より後であることを確認する。
4. システムは **整備記録** を作成する。
5. システムは「整備記録一覧画面」に登録した整備記録と機材の次回整備期限を表示する。

## 代替コース
- **2a. 機材が存在しない**: システムは「整備記録登録画面」に「該当する機材がありません」と表示する。
- **3a. 次回整備期限が実施日時以前**: システムは「整備記録登録画面」に「次回整備期限は実施日時より後にしてください」と表示する。
