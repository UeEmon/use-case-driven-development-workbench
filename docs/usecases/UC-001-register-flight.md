# UC-001 運航便を登録する

**主アクター**: 運航管理者　**事前条件**: 運航管理者がログインしている　**事後条件**: 機材未割当の **運航便** が登録されている

## 基本コース
1. 運航管理者は「運航便登録画面」で便名・運航日・出発 **空港**・到着 **空港**・出発/到着予定時刻・使用 **機種** を入力し、登録ボタンを押す。
2. システムは出発空港と到着空港が異なり、到着予定時刻が出発予定時刻より後であることを確認する。
3. システムは同じ運航日に同じ便名の **運航便** が存在しないことを確認する。
4. システムは機材未割当の **運航便** を作成する。
5. システムは「運航便一覧画面」に登録した運航便を表示する。

## 代替コース
- **2a. 入力内容が不正**: システムは「運航便登録画面」に不正な項目と理由を表示する。
- **3a. 便名が重複**: システムは「運航便登録画面」に「同じ運航日に同じ便名が登録済みです」と表示する。
