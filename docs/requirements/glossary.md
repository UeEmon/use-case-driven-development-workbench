# 用語集

対象: 航空会社の **運航便** と **機材**（航空機）を管理する運航管理システム。

| 用語 | 英語名（クラス名） | 説明 |
|---|---|---|
| 運航管理者 | Dispatcher | 運航便の計画と機材割当を行う職員 |
| 整備士 | Mechanic | 機材の整備を実施し、整備記録を登録する職員 |
| 空港 | Airport | 発着地。IATA 3 レターコード（例: HND）で識別する |
| 機種 | AircraftType | 航空機の型式（例: B787-9）。座席数・航続距離を持つ |
| 機材 | Aircraft | 会社が運用する航空機 1 機。機体登録記号（例: JA801A）で識別する |
| 機材群 | Fleet | 会社が保有する機材の集合。割当候補の検索窓口 |
| 運航便 | Flight | 便名・運航日・出発/到着空港・出発/到着予定時刻・使用機種を持つ 1 回の運航 |
| 機材割当 | AircraftAssignment | 運航便に機材を割り当てた記録。割当日時と割当者を持つ |
| 整備記録 | MaintenanceRecord | 機材に実施した整備の記録。実施日時と次回整備期限を持つ |
| 整備予定 | MaintenanceSchedule | 機材を運航から外して整備する予定期間 |
| 耐空性 | （Aircraft の判定） | 機材が安全に運航できる状態。直近の整備記録の次回整備期限が切れていないこと |
| ターンアラウンド時間 | （Fleet の定数） | 到着から次の出発までに最低限必要な地上時間。既定値 45 分 |
